# homework-V2 · 产品方案

## 1. 定位与目标用户

**定位**：面向 6-9 年级学生**家长**的 AI 家教——优先把题目讲透，批改是附带价值。

**用户**：家长（使用者）、孩子（受益者）。**不含**老师角色。

**一句话价值主张**：拍张作业图，AI 把每道题的**解题思路和答案**讲给你，孩子的作答能核对就核对，错题自动沉淀成错题本。

## 2. V1 范围（本版本上线目标）

| 维度 | V1 |
|---|---|
| 学科 | **数学**（6-9 年级） |
| 入口 | 微信（经 OpenClaw 插件转发） |
| 输出 | 局域网 HTML 页（Next.js）· 微信回推短链 |
| 模型 | 全部在线 API：**Claude Sonnet 4.6** + **Codex (GPT-5.4)** |
| 本地模型 | V1 **不启用**（Feature Flag `LOCAL_VLM_ENABLED=false`） |
| 绑定 | 1 个微信 openId = 1 个孩子 |
| 错题本 | 按**知识点 + 日期**归类 |
| 教材章节上传 | **V2 再加**，V1 不做 |

## 3. 核心产品理念

### 3.1 "读准题 > 批准答"

传统方案把精力放在"判学生答案对错"，本产品翻转优先级：**先让 AI 把印刷题读准、把图表理解准、把解题过程讲清**。学生答案只是副产品。

原因：
- 读题是上游，读错了下游一切崩盘
- 家长真正需要的是**辅导能力**，不是判分器
- 判分误判会让家长失去信任，"能批就批、不能批就跳"体验反而更好

### 3.2 "能批就批，不能批就不批"（二态 + 跳过）

对每道题：
- ✓ **正确**：高置信确认学生答案与 AI 答案一致
- ✗ **错误**：高置信判学生答案错 + 给出订正
- — **未批改**：学生答案模糊/无法定位/AI 不确定，不强判，只展示解答

**不设"⚠ 待确认"**——家长没有复核义务，含糊态只会造成决策负担。

### 3.3 所有题都生成讲解

无论对错，每道题都输出"解题思路 + 最终答案"。这是产品**差异化的核心**——它是 AI 家教，不是判分器。

## 4. 用户流程

```
[家长] 微信发送作业图
   ↓
[系统] 回复"正在批改中，约 30 秒..."
   ↓
[家长] 收到短链 https://<内网IP>:3100/r/{shortId}
   ↓
[家长] 打开链接 → 看到大题-小题层级的讲解页
   ↓
[家长] 对错题点"加入错题本"（或默认自动加入）
   ↓
[家长] 稍后访问错题本页，按知识点复习
```

### 5.2 错题本页 `/mistakes`

- 默认按**时间轴**展示
- 筛选：知识点、日期范围、对错状态
- 每条错题：题目截图 + AI 解答 + 加入时间 + 知识点标签
- 操作：标记"已掌握"（隐藏但保留）/ 删除 / 查看原作业

### 5.3 练习页（V2 预留）

基于错题本的知识点分布生成变式题包。V1 仅占位路由。

## 6. 三态判定规则（仅 V1 数学）

| 条件 | 结果 |
|---|---|
| AI 自解 + SymPy 验证**一致** & 学生答案**可识别** & 匹配 | ✓ 正确 |
| AI 自解 + SymPy 验证**一致** & 学生答案**可识别** & 不匹配 | ✗ 错误 |
| AI 自解 + SymPy **不一致** | — 未批改（只展示解答，不下判定） |
| 学生答案**无法识别** | — 未批改 |
| 图像模糊/截断/题面识别失败 | — 未批改，提示重新拍 |

## 7. 错题本归类

### 7.1 标签维度（V1）

- **知识点**（`knowledge_tag`）：来自内置 K12 数学知识点树（~300 节点，6-9 年级）
- **日期**（`created_at`）：自动
- **错因**（`error_type`，可选）：概念不清 / 计算失误 / 漏解 / 题意理解偏差（LLM 生成时结构化输出）

### 7.2 视图

- 时间轴视图：按日期倒序
- 知识点视图：按知识点分组聚合
- 薄弱点 Top 5：近 30 天错误率最高的知识点（简单统计）

## 8. 数据与隐私

- 图片、批改结果**只存本地**（Win 本机 SQLite + 本地文件系统）
- 不上云，不共享
- 家长可随时删除某份作业 / 清空错题本

## 9. 非目标（明确不做）

- 老师/机构端
- 答案库/题库采买
- 作业打印/下发
- 社交/排行榜
- V1 不做语文作文/阅读、英语作文（AI 能力边界，不承诺）

## 10. 成功指标（V1 验收）

| 指标 | 目标 |
|---|---|
| 端到端批改耗时（20 题数学） | P50 ≤ 35s |
| 单份作业成本（在线 API） | ≤ ¥0.8 |
| 题面识别准确率（含简单图表） | ≥ 90% |
| 自解题答案正确率（与人工校对） | ≥ 88% |
| 学生答案识别覆盖率 | ≥ 60%（剩余标为"未批改"） |
| 家长"批改有误"反馈率 | ≤ 10% |
